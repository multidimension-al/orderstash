# Security and privacy reports

OrderStash v0.1.0 is in development. There is no published stable release or
security-support schedule. Reports against the current source are welcome.

Do not post private invoices, account data, cookies, profiles, credentials,
payment details or sensitive exploit material in public issues.

Check the repository's **Security** tab for private reporting options. If private
reporting is unavailable, open an issue requesting a private channel without
including sensitive details. No dedicated support email or hosted reporting
service is configured yet.

Provide the affected version, Chrome version, workflow or permission involved,
a minimal reproduction and observed impact. Use synthetic records where possible.
For ordinary UI and layout reports, see [Contributing](CONTRIBUTING.md).

See [Privacy](PRIVACY.md) and [Permissions](docs/PERMISSIONS.md) for current behavior.
