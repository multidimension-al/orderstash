# Contributing

OrderStash is in development at v0.1.0. Start with the
[development setup](docs/DEVELOPMENT.md) and [user guide](docs/USAGE.md).

Include reproduction steps for bug fixes and describe the resulting behavior.
Run typechecking, relevant unit/Chrome tests and the publication audit. Use
synthetic fixtures for automated tests. Update usage, privacy and permission
documentation when behavior changes.

Keep local notes, prompts, transcripts, browser profiles and test artifacts out
of contributions. Only public source, tests, finished assets and documentation
belong in commits. Preserve access cooldowns and the strict content security policy.

## Problem reports

Include OrderStash/Chrome versions, marketplace, action, displayed status and
reproduction steps. Remove real order numbers, greetings, addresses, payment
labels and tokens. Prefer minimal synthetic HTML fixtures for layout issues.
Do not submit profiles, cookies, private invoices or full authenticated pages.
See [Security](SECURITY.md) for sensitive reports.
